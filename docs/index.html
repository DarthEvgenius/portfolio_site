About Me

Hello! I’m Eugene, a frontend web developer with a year and a half of commercial experience. My journey in web development has been both exciting and challenging, allowing me to grow and hone my skills in various technologies and frameworks.

Here it is my work experience:

'Joki-Joya' — family amusement parks with well-developed IT infrastructure:

  • Tech stack: TypeScript, Nuxt 3, Vue 3, Pinia, Vue Router, GSAP, SCSS, ESLint, Yandex Maps API, Chart.js, Vuetify.
  • Project Configuration: Set up ESLint for code quality maintenance, Nuxt.config for module management, sitemap generation for dynamic pages, and integration of SEO scripts.
  • Integration and configuration of Nuxt modules (Yandex Metrika, Yandex Maps, @nuxt/image, sitemap).
  • Developed an internal analytics dashboard using Chart.js and Vuetify for SEO data analysis, providing the marketing department with a user-friendly tool for visualizing key metrics.
  • Conducted comprehensive refactoring and optimized application performance, resulting in Lighthouse scores improving from 20/45 to 90+/55 and enhanced Core Web Vitals metrics.
  • Created an internal component library for payments, booking, regional SEO optimization tasks, and quick implementation of seasonal and trial promotions, as well as landing pages.
  • Implemented a routing system with middleware validation for dynamic regional pages, enabling flexible content management based on user geolocation.

'Sigma' — Corporate Solutions for the Public Sector, Development of High-Load Billing Products at the «1C» Level:

  • Tech stack: JavaScript, ExtJS, OOP, SCSS/Sass.
  • Development and maintenance of interfaces for high-load billing systems using JavaScript and the ExtJS framework.
  • Participation in the project lifecycle within a large team: code reviews, task planning, deadline estimation, and collaborative architectural decision-making.
  • Worked with a large legacy codebase built on OOP principles. Conducted refactoring to improve code readability and maintainability, and wrote documentation.
  • Developed and implemented an Event Bus for decentralized interaction and synchronization of complex document objects across different nesting levels, simplifying the application architecture and reducing component coupling.
  • Reorganized the styling system at the project level: edited and created SCSS/Sass mixins and unified the code across multiple projects, increasing development speed and ensuring UI consistency.
